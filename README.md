# 🚀 Machine Learning Zoomcamp 2026 - Module 1

This repository contains my personal solutions and notes for the **Module 1 Homework** of the [Machine Learning Zoomcamp 2026](https://github.com/DataTalksClub/machine-learning-zoomcamp) by DataTalks.Club.

## 📝 What I Learned
In this introductory module, I refreshed my foundational knowledge and practically covered:
- **Machine Learning Concepts:** ML vs. Rule-based systems, Supervised Learning, and the CRISP-DM framework.
- **Environment Setup:** Setting up Python, Jupyter Notebook, and managing dependencies.
- **Data Manipulation:** Data exploration, handling missing values, and preprocessing using **Pandas**.
- **Linear Algebra:** Translating mathematical matrix operations into code using **NumPy**, culminating in implementing the core engine of Linear Regression from scratch!

## 📊 Dataset Used
- **Car Fuel Efficiency 2026 Dataset**
- Explored total records, unique fuel types, filled missing values using mode, and calculated medians.
